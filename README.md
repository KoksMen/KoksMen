## 🇷🇺 Обо мне

Приветствую! Меня зовут **Никита** (`KoksMen`). 👋

Я Software Engineer с глубоким фокусом на стеке **.NET (C#)**, низкоуровневых механизмах **Windows Internals (Windows Credential Provider V2, LogonUI, Winlogon)**, архитектуре криптографически защищенных клиент-серверных систем и создании эргономичных десктопных приложений (**WPF / Windows 11 Fluent Design**).

### 🔍 Ключевые направления и экспертиза:
- 💻 **Системная разработка под Windows:** Проектирование кастомных провайдеров учетных данных (**Credential Provider V2 COM**), прямое взаимодействие с экраном блокировки Windows 10/11 и диалогами контроля учетных записей (**UAC**).
- 🔐 **Прикладная безопасность и криптография (AppSec):** Построение систем двухфакторной аутентификации (**2FA PIN** на базе **PBKDF2-SHA256** с индивидуальной криптографической солью и защитой от перебора), изоляция учетных записей по **SID**, сессионные льготные периоды с аппаратной привязкой к аптайму (`Environment.TickCount64`).
- 📡 **Сетевые протоколы и низкая задержка:** Реализация защищенных локальных каналов связи через **mTLS WebSocket** (RTT < 15 мс) и автономный **Bluetooth RFCOMM** канал.
- 🎨 **Десктопный UX и Modern UI:** Разработка нативных интерфейсов на **WPF / XAML** с применением кастомных контролов, плавных анимаций и принципов **Fluent 2 Design**.
- 🌐 **Backend & Microservices:** Проектирование REST API, клиент-серверных приложений и сервисов на **ASP.NET Core**, **Entity Framework Core** и **LINQ**.

## 🇬🇧 About Me

Greetings! I'm **Nikita** (`KoksMen`). 👋

I am a Software Engineer focused on the **.NET (C#)** ecosystem, **Windows Internals (Windows Credential Provider V2, Winlogon/LogonUI)**, high-security client-server networking, and polished desktop experiences (**WPF / Fluent 2 Design**).

### 🔍 Core Focus Areas:
- 💻 **Windows Systems Programming:** Custom Credential Provider V2 development, integrating directly into Windows 10/11 lock screen and UAC elevation dialogs.
- 🔐 **AppSec & Cryptography:** 2FA PIN implementation using **PBKDF2-SHA256** with per-account salt, brute-force guard (3-attempt lockout), SID-first account isolation, and monotonic uptime grace period tracking.

- 🎨 **Desktop Ergonomics:** Crafting desktop interfaces with **WPF**, custom XAML controls, and Windows 11 **Fluent Design** principles.
- 🌐 **Backend Engineering:** Scalable REST Web APIs, background services, and data layers built with **ASP.NET Core** and **EF Core**.

## 🚀 Главные проекты | Featured Projects

### 🔮 [Portal-Windows](https://github.com/KoksMen/Portal-Windows)
<p align="center">
  <img src="./assets/herta.gif" alt="Herta Mascot" width="130" />
</p>

> **Бесшовная, безопасная и мгновенная биометрическая разблокировка Windows со смартфона или умных часов**  
> *Seamless, secure, and instantaneous Windows unlocking using smartphone or smartwatch.*

- 🌟 **Кастомный Windows Credential Provider V2:** Встраивается прямо в экран блокировки Windows 10/11 и системные диалоги подтверждения UAC.
- 🔐 **2FA PIN & PBKDF2-SHA256:** Двухфакторная аутентификация со 100 000 итераций PBKDF2, индивидуальной криптографической солью и защитой от перебора (блокировка после 3 неверных попыток).
- ⏳ **Динамический прогресс-бар и стили LogonUI:** Нативный таймер и анимация marquee (`[████]`, `[━━━━]`, `[●●●●]`) прямо на плитке пользователя.
- 📡 **Двойной транспорт связи:** Сверхбыстрый локальный mTLS WebSocket (< 15 мс) по Wi-Fi/LAN и автономный канал Bluetooth RFCOMM при отсутствии сети.
- 🆔 **SID-First Identity:** Привязка доверенных устройств к уникальному идентификатору SID учетной записи с поддержкой локальных, Microsoft (MSA) и доменных (AD) аккаунтов.
- 📱 **Экосистема:** Работает в тандеме с клиентом [Portal-Android](https://github.com/xXMRK888YTXx/Portal-Android) (Google Play / Wear OS).
